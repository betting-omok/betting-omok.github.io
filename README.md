# 베팅 오목

세 칸을 고르고 점수를 몰래 걸어 돌을 놓는 2인 전략 오목입니다.

- 바로 하기: https://betting-omok.github.io/
- 개인정보처리방침: https://betting-omok.github.io/privacy.html

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 게임 전체(빌드 결과물) |
| `firestore.rules` | Firebase 보안 규칙 |
| `sw.js`, `manifest.json`, `icons/` | 설치형 웹앱(PWA) 파일 |
| `version.json` | 배포 버전. 앱이 이 값으로 새 버전 알림을 띄움 |
| `privacy.html` | 개인정보처리방침 |
| `tools/` | 빌드 스크립트 |
